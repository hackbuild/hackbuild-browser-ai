# @hackbuild/ai-elements

> Deprecated: use [@hackbuild/ai-views](https://hackbuild.github.io/hackbuild-browser-ai/docs/ai-views/llms.md), which draws the same views with hackbuild-ui as custom elements and Vue components.

Generated by tools/llms.mjs from the TypeDoc JSON, the README and the examples of hackbuild-browser-ai. Human docs: https://hackbuild.github.io/hackbuild-browser-ai/docs/ai-elements/

Deprecated: use @hackbuild/ai-views (https://hackbuild.github.io/hackbuild-browser-ai/docs/ai-views/llms.md).

## Purpose

- `define(prefix = "hb")` registers the ai-views custom elements under the prefix and writes one deprecation note to the console.
- `ELEMENT_NAMES`, `mountMemoryInspector`, `traceRows` and `inspectorHtml` are re-exported from ai-views.
- The model picker, download bar, status pills and chat panel of 0.1 are gone; use `<model-select>`, `<chat-pane>` and `<chat-composer>` from ai-views.

## Install

```sh
npm install @hackbuild/ai-views
```

Existing code that imports the old name keeps working with `npm install @hackbuild/ai-elements`.


## Mistakes to avoid

- You start new code on @hackbuild/ai-elements. It is deprecated; install @hackbuild/ai-views and import `define` from `@hackbuild/ai-views/elements`.
- You look for the 0.1 model picker, download bar, status pills or chat panel. They are gone; use `<model-select>`, `<chat-pane>` and `<chat-composer>` from @hackbuild/ai-views.
- You expect bare tag names from this package's `define()`. Its prefix defaults to `hb`, so you get `<hb-model-select>`; the ai-views `define()` registers bare names by default.
- You leave out the stylesheet. The elements draw with the page's hackbuild-ui stylesheet, so install @virgilvox/hackbuild-ui as the peer and load its CSS.
